# Qwen-Image (`qwenimage`)

Category: Image. From Forge's prompt library. The 9-part master prompt behind every model is in `../master-prompt.md`.

**What it does.** 3.0 Pro by Alibaba. Built for one-pass dense layouts: infographic grids, newspaper pages, academic-paper mockups, nested UI, multi-line maths notation, and it renders text as small as ten pixels legibly across twelve languages. The strongest option for dense Chinese text. Weak at portrait photorealism, rate-limited to five requests a minute, no open weights at this tier.
**Write it as.** A very long, layout-explicit prompt, 150 to 600 words. Describe every region and what it contains. This is the one model where length is the point.
**Settings.** `size` uses an asterisk: 1024*1024, not 1024x1024. Set `prompt_extend` to false or it rewrites your work.
