# Seedream (`seedream`)

Category: Image. From Forge's prompt library. The 9-part master prompt behind every model is in `../master-prompt.md`.

**What it does.** 5.0 Pro by ByteDance. Ten-plus languages natively with correct script direction and diacritics: the right routing for Arabic, Hebrew and Thai typography. Complex information visualisation, pixel-level editing, photoreal textures. Weak points: portrait photorealism trails Nano Banana Pro, no native 4K, no seed, no batch.
**Write it as.** Prose, 60 to 200 words. Write the spatial arrangement explicitly, quote the exact on-image text, then state the reading order. The cap is 4000 tokens but stay under about 600 English words.
**Settings.** Request 1.5K, never 1K: same price, better image. `n` is locked to 1.

**Master prompt (SR-00)**

```

Bottom band, light blue: the line "Sunday 15 March, 10:00 to 14:00" in English on the left and "יום ראשון, 15 במרץ" on the right in Hebrew. Reading order: title, illustration, date. No other text anywhere. size 1.5K, aspect 3:4.
```
