# v0 (`v0`)

Category: App builders. From Forge's prompt library. The 9-part master prompt behind every model is in `../master-prompt.md`.

**For every app builders model.** Three rules hold across every builder: plan first, one slice at a time, and always say what to leave alone. A prompt that describes a whole app produces an app-shaped demo, not a working slice.

**What it does.** v2 API by Vercel. Headless as well as interactive. Each app is a chat that holds its own state, and the model is a composite that can change under you. Next.js, React and Tailwind on Vercel, invoked from your own product or CI. Off-stack requests degrade.
**Write it as.** A Next.js, React and Tailwind brief. Do not hard-tune prompts to a base model's quirks: v0 swaps them independently.
**Watch out.** Three skills per request is a hard cap.

**Master prompt (V0-00)**

```
Build the first slice of a quiz app in Next.js App Router with Tailwind: one page at /quiz that loads questions from a local JSON file, shows one multiple-choice question at a time with four buttons, tracks the score in React state, and shows a results card at the end with a "Play again" button. Mobile first, 16px gutters, no horizontal scroll. No auth, no database, no leaderboard yet. Use shadcn/ui Button and Card only.
```

1. **V0-01** Landing page for a study-timer app: hero with headline and one call to action, three feature cards, a footer. Next.js, Tailwind, mobile first. No forms yet.
2. **V0-02** Add to the existing quiz app: a /results page reading the score from the URL query and showing a share button that copies a link. Leave /quiz untouched.
3. **V0-03** A settings page with three toggles (dark mode, shuffle, timer) stored in localStorage, using shadcn/ui Switch. Next.js App Router.
4. **V0-04** A responsive leaderboard table with name, score, date, sortable by score, using shadcn/ui Table, fed by a local JSON array. No backend.
5. **V0-05** A dark-mode toggle in the header that respects prefers-color-scheme and persists. Tailwind dark: classes. Touch only the header component.
6. **V0-06** A sign-in form UI with email and password fields and validation messages, using shadcn/ui Form. UI only, no submission logic.
7. **V0-07** A pricing section with three tiers as cards, one highlighted, monthly and yearly toggle. Tailwind, mobile first.
8. **V0-08** Headless from CI: generate a Next.js page /status that reads a JSON file of test results and shows a green or red badge per suite. Return only the file contents.
9. **V0-09** A 404 page matching the existing site header and footer, with a search box that routes to /search?q=. Leave other pages alone.
10. **V0-10** Convert the existing /quiz page to load questions from /api/questions (a route handler returning the local JSON). Do not change the UI.
11. **V0-11** A contact form using Server Actions that logs the submission to the console and shows a success toast. shadcn/ui Input, Textarea, Button.
12. **V0-12** An empty-state component for the leaderboard: an illustration placeholder, one sentence, and a button to /quiz. Use it only when the array is empty.
