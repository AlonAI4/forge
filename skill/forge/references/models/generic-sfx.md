# Any other sound model (`generic-sfx`)

Category: Sound effects. From Forge's prompt library. The 9-part master prompt behind every model is in `../master-prompt.md`.

**What it does.** The wildcard. A portable sound-design brief with the source, the space, the capture and the shape of the envelope.
**Write it as.** Name the source, the material it hits, the space it happens in, and how the tail behaves. That is the whole craft. One event per generation, everywhere. Layer in a DAW.

**Master prompt (GSX-00)**

```
Source: a glass bottle. Material: dropped onto a concrete floor. Space: a small empty garage, slight natural echo. Capture: close, dry. Envelope: sharp shatter transient, scattered small tinkles for about two seconds, then silence. One event, 3 seconds.
```
