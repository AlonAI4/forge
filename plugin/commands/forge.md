Use Forge to write the best prompt for this request: $ARGUMENTS

If the request above is empty, ask the person in one short line what they want made and for which AI (if they know), then continue.
Use the Forge tools below; you do not need to load the forge skill for this. Keep it quick: as few rounds as possible.

1. **Start, in one call.** Call `forge_start` with the request, `ai` if the person named one (an everyday name or a version is fine: ChatGPT, Veo 3, Midjourney v7), `kind` if they named no AI and you can tell what they want made (image, video, voice, sfx, music, text, code, app, research), and `skip_questions: true` if they said to skip the questions or want it now. It returns the AI (picked for you if they named none: tell them the pick and its reason in one sentence), up to 3 questions, and Forge's brief. Do not show the brief.
2. **Ask the questions, right here in the chat** (skip this step if they said skip; with no questions from Forge, ask your own only when the result depends on something only the person knows). Forge's questions are suggestions, best first. Ask at most 3 in total, the ones whose answers would change the result most. Drop any the request already answers; replace or merge any of Forge's questions, the first one included, with a sharper question about the same thing for this request (ask for the exact figures, names or words the result needs, not a general list), and keep Forge's field as the key of a question you replaced so forge_brief still puts the answer in its place. A sharpened question keeps an open ending ("...and anything else it must show, say or feel like?"), because people answer only the examples you list: never drop Forge's last open question, and never spend a question on something the result does not depend on. When Forge gives fewer than 3, you may add your own about things only the person knows that the result depends on: names, exact words, numbers, what their own thing looks like, limits such as budget or time. Key the answer to each question of your own by that question itself, never by a field Forge asked about: two answers under one key overwrite each other. If you have the AskUserQuestion tool (Claude Code), ask them all in ONE call: one question each, a short header, its choices as options (up to 4); for a question with no choices, offer 2 or 3 likely answers yourself, using its example as a guide. Without that tool, ask them all in one short message. Never ask something they already said. If they answer, call `forge_brief` with the request, the AI id and their answers keyed by each question's `field` (your own questions keyed by the question itself), and write from that brief instead.
3. **Write the prompt and check it in the same reply.** Write the prompt from the brief (follow its RULES and REPLY WITH shape) and call `forge_check` with the same request, AI id, answers and your prompt, with no text before it. If `ok` is false: when `fixed_ok` is true, the `fixed_prompt` already passed, so use it; otherwise fix every problem and call `forge_check` again. **Never show a prompt that has not passed.** Up to 3 tries; if it still fails, show it and say plainly which problems are left. `notes` are hints, not errors.
4. **Show the result**: the final prompt in a code block, then the negative prompt and settings if there are any, then one line on what to paste where. No other commentary.
5. **Use it now, or copy.** Always keep the code block so they can copy it. Then ask in one line if they want it used now:
   - for Claude itself (a chat, writing or coding job you can do here): when they say yes, run the prompt yourself in this chat;
   - for another AI with a connected tool in this session (an image, video or music generator): offer to send it there, and only send after they say yes (it may cost credits);
   - otherwise they copy it into that AI.

**Prompt Doctor.** When the person pastes a prompt of their own and asks to make it better, fix it or check it, run the same steps with their whole message as the request, unchanged. Forge finds the pasted prompt and reads it as the material: write a better prompt for the same job, keep what it got right (its subject, names, numbers, quoted words and real settings), fix the rest, and do not copy it word for word. `forge_check` never asks for the old prompt word for word.

"Read this chat" is off: do not call `forge_chat_context` unless the person asks for Forge to read this chat.
